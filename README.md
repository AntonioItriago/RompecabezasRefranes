# RompecabezasRefranes
Telegram Mini App (TMA) en HTML5/JS de un juego casual de puzzle. Los jugadores ordenan fichas de palabras para descifrar refranes populares venezolanos. Incluye mecánica de monetización con anuncios recompensados (Rewarded Ads) para desbloquear pistas y revelar la primera palabra.
🧩 Rompecabezas de Refranes Venezolanos
Telegram Mini App (TMA) desarrollada con HTML5, CSS3 y JavaScript vanilla. Un juego casual interactivo donde los usuarios ordenan palabras para descifrar la sabiduría popular de los refranes venezolanos.

📋 Descripción General
Rompecabezas de Refranes es una Telegram Mini App ligera y responsive orientada al entretenimiento y agilidad mental. Inspirado en la cultura tradicional venezolana, el juego desafía al usuario a organizar correctamente fichas de palabras desordenadas para completar refranes típicos nivel a nivel.

El proyecto incorpora un modelo de monetización mediante anuncios recompensados (Rewarded Ads), permitiendo a los jugadores obtener pistas para revelar la primera palabra cuando se encuentran atascados en un refrán difícil.

✨ Características Principales
Mecánica Interactiva: Selección e intercambio de fichas de palabras táctiles adaptadas a pantallas móviles.

Integración Nativa con Telegram: Soporte para @telegram-apps/sdk, ajuste de temas (Modo Claro / Oscuro) y navegación nativa.

Monetización con Rewarded Ads: Sistema de ayuda integrado donde el usuario ve un anuncio para desbloquear la primera palabra del nivel.

Arquitectura Ligera: Desarrollo client-side sin dependencias pesadas, optimizado para carga rápida en Telegram.

Diseño Responsive: Adaptado para dispositivos móviles iOS y Android dentro del entorno de Telegram.

🛠️ Tecnologías Utilizadas
Frontend: HTML5, CSS3, JavaScript (ES6+)

Plataforma: Telegram Mini Apps API (telegram-web-app.js)

Monetización: SDK de Redes de Anuncios Recompensados (Telegram Ads / Monetag / Adsterra)

Despliegue: Vercel / GitHub Pages / Netlify
